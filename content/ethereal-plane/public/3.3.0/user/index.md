title: "Ethereal Plane"
---

Ethereal Plane connects your stream to your Foundry game. You can bring in chat, run viewer polls, and use stream events to trigger macros.

This is the guide for **3.3.0**. The release requires Foundry **13 through 14**.

[Get started](./getting-started/) with installation and setup.
