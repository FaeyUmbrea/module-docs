---
title: "Chat and channel-point triggers"
---

Triggers connect stream events to macros in your world. Configure the event in Ethereal Plane's web interface, then assign the macro in the module's trigger menu.

A chat-command event listens for the commands you configure. A channel-point event connects a Twitch reward to the trigger where that feature is available for your account.

## Start small

Choose a macro with a clear, harmless result for your first test. Run it directly in Foundry, assign it to the trigger, then try the chat command or reward.

Once it works, swap in the action you actually want. This makes it easier to tell a connection problem from a macro problem.

## When it doesn't fire

Check that the module and trigger processing are both enabled. Then check the trigger's event and its macro assignment. A connected chat view and enabled trigger processing are separate things.

The trigger menu's import and export buttons let you move your assignments between worlds.
