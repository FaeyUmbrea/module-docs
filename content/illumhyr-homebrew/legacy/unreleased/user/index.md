Illumhyr Homebrew contains Pathfinder 2e content for my Illumhyr setting.

The documentation does not yet have a verified published release for this module. Treat the available content as development material until a release is linked here.

## Use it in a world

Enable the module in a Pathfinder 2e world, then look for its compendiums in the Compendium sidebar. Import the entries you want into your world so you can work with them there.

The module is setting content, rather than a general-purpose replacement for the Pathfinder 2e system.
