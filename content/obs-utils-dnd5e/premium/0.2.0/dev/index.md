The published 0.2.0 companion supplies actor-value labels and transformation tracking for OBS Utils on Foundry 11. Its module ID is `obs-utils-dnd5`.

This release has no published type archive. The generated API reference for OBS Utils 5.3 describes a newer host and should not be used as the compatibility contract for this companion.

For the released implementation, use the [0.2.0 source](https://github.com/FaeyUmbrea/obs-utils-dnd5e/tree/0.2.0). New companion integrations belong to their own module release and documentation version.
