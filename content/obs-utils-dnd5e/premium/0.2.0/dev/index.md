The published 0.2.0 companion supplies actor-value labels and transformation tracking for OBS Utils on Foundry 11. Its module ID is `obs-utils-dnd5`.

This companion targets Foundry 11; the OBS Utils 5.3 API targets a newer Foundry version.

For the released implementation, use the [0.2.0 source](https://github.com/FaeyUmbrea/obs-utils-dnd5e/tree/0.2.0).
