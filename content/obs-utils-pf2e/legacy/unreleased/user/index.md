This companion adds Pathfinder 2e actor values and system-specific events to OBS Utils. It is in development; there is no published release to install from this documentation yet.

Enable it alongside one supported OBS Utils host in a Pathfinder 2e world. The companion checks that its host provides the API it needs.

## What it adds

The grouped value picker helps you find system fields without guessing their paths. The companion also supplies system events for triggered overlays.

## When a field is empty

Check that the selected actor has the data you are trying to display. Not every actor type has every field. A missing value should not be treated as zero.

Release-specific installation and compatibility details will appear here when the module is released.
