title: "OBS Utils"
---

OBS Utils connects your Foundry game to OBS Studio. It gives the stream its own view, lets you build overlays from actor values, and can switch OBS scenes in response to Foundry events.

Start with [Getting started](./getting-started/) to connect your browser source. Then open the [Stream Composer](./stream-composer/) to build an overlay.

## What you can do

- Track a GM or a player with the stream camera.
- Put names, portraits, health bars, and other actor values on the stream.
- Use Foundry events to drive overlay triggers and OBS actions.
- Import and export overlay bundles.

For older feature walkthroughs, use the **Legacy** channel. They are preserved separately because their exact release coverage has not been verified.

Writing an integration? [Developer docs](../dev/) includes the reference generated from the 5.3.0 release.
