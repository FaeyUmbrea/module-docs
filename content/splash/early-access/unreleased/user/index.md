---
title: "Splash early access"
---

These pages cover the early-access edition of Splash while it is in development. There is no published release snapshot for this edition yet.

For installation and available features, use the [public Splash guide](/splash/public/user/).

When installing an early-access edition, enable that edition instead of the public one. They share a module ID and are alternatives, rather than modules to run together.

For help with early access, use [Discord](https://discord.com/invite/WfMaKPPdeM).
