title: "Integrating with Splash"
---

Splash has two different interfaces: the module API for integrations, and a small set of helpers passed to Script actions inside a running splash. Use the one that fits your job.

- [Module API](./module-api/) covers opening a splash and registering an action type.
- [Script actions](./scripting/) covers state changes, values, closing, and door helpers inside a splash.

These guides are checked against **Splash 1.1.0**. This release has no published declaration archive, so the examples come from its tagged implementation rather than a generated reference.

The [previous integration guide](/splash/legacy/current/dev/api/) is preserved for older versions. Use the release-specific guides here when its signatures differ.
