---
title: "The Splash editor"
---

A splash is a journal page you can arrange visually. Give it an image, some text, and a button, then preview it before adding more. You don't need to write code to make it interactive.

## Objects and states

Objects are the things on the screen: images, text, buttons, panels, gauges, videos, hotspots, text inputs, draggable pieces, and drop zones. Add an object from the **+** in the Objects panel and select it to edit its properties in the inspector.

A **state** is an arrangement of those objects. An object can appear in several states with a different position or size in each. If it isn't placed in the active state, it won't appear there. Use the eye toggle in the object list to place or remove it.

Start with one state. Add another when you need a second screen, an answer reveal, or a different stage of a puzzle. Mark the state you want to open with as **initial**.

## Arrange the screen

Drag objects to move them and use their handles to resize. Guides help them line up; hold **Alt** to move without snapping. Select several objects when you want to move them together.

Groups keep related objects together. Double-click a group to work on its individual objects, then press **Escape** to leave it.

## Preview and save

The editor saves changes to the journal page as you work. **Undo** and **Redo** are there when you need them; **Preview** opens the splash locally so you can try its buttons and layout.

A preview is just for you. Once you're happy with it, choose how to [show it to the table](../layers-and-modes/).
