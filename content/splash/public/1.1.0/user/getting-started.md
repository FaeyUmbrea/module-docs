---
title: "Getting started"
---

Install **Splash: Interactive Handouts** through Foundry's module installer and enable it in your world. Install and enable libWrapper too.

Open a Splash journal page to edit it. Start with an image and some text before adding interactivity; that makes it easier to check the layout.

Preview your handout before launching it for the table. A local preview is useful while you are still moving things around.

The [previous editor guide](/splash/legacy/current/user/editor/) includes a longer walkthrough and screenshots. Those pages are preserved as legacy documentation because their release coverage is not verified.
